# 🚗 LiCar — Сервис аренды автомобилей

Учебный fullstack-проект, разработанный в рамках выпускной квалификационной работы. Сайт демонстрирует современный подход к созданию веб-приложений: от адаптивной вёрстки до интерактивных элементов на JavaScript.

## 👨‍💻 Автор
**Ликонцев Архип Матвеевич**

## 🛠️ Стек технологий
- **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, Grid), JavaScript (ES6+)
- **Фреймворки/Библиотеки:** Bootstrap 5, Bootstrap Icons
- **Шрифты:** Science Gothic (Google Fonts)
- **Инструменты:** Git, GitHub, VS Code

## ✨ Реализованный функционал
- ✅ Адаптивная вёрстка (Mobile First, корректное отображение на всех устройствах)
- ✅ Кастомная цветовая палитра с использованием CSS-переменных и градиентов
- ✅ Плавная прокрутка к якорным ссылкам (Smooth Scroll)
- ✅ Анимация появления карточек при скролле (Intersection Observer API)
- ✅ Структурированная архитектура проекта (разделение HTML, CSS, JS)
